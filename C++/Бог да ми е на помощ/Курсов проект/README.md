# Student Management System

## Описание

Конзолно приложение на C++, което позволява добавяне, извеждане и съхраняване на информация за студенти и техните оценки, както и изчисляване на среден успех.

## Условие на задачата

Да се дефинира базов клас за студент зададен с име, факултет, факултетен номер и номер на група. Да се дефинира производен клас за успех зададен с два масива от оценките по всички дисциплини за два семестъра (броят на оценките за всеки семестър е 5). Класовете да включват конструктори без параметри за попълване на член-променливите в диалог. Да се определят и извеждат средният успех за всяка група и максималния и минимален среден успех за зададена група. Да се извеждат оценките за всеки студент и за студентите от зададена група. Да се предефинира операцията <<, която да се използва за извеждане на данните. Данните да се съхраняват във файл.

## Файл с данни

В проекта е включен файл `data/students.txt`, съдържащ примерни записи за студенти. При стартиране програмата зарежда наличните данни от него. Можете да използвате примерните записи и да добавяте нови студенти чрез менюто на програмата.

Програмата не поддържа редактиране или изтриване на вече записани студенти. Ако искате да правите някакви промени по файла, ще трябва да го направите ръчно.

## Стартиране

Необходим е C++ компилатор с поддръжка на C++23.

**Чрез VS Code:**

1. Отворете основната директория на проекта във VS Code.
2. Натиснете `F5`, за да компилирате и стартирате програмата (необходима е подходяща конфигурация за вашата среда).

**Чрез терминал:**

Отворете терминал в основната директория на проекта и изпълнете командата за компилация.

**Windows:**

```bash
g++ -std=c++23 -Wall -Wextra -pedantic src/main.cpp src/Student/Student.cpp src/StudentGrades/StudentGrades.cpp src/StudentManager/StudentManager.cpp -o StudentManagement.exe
```

Стартиране в PowerShell:

```bash
.\StudentManagement.exe
```

**Linux / macOS:**

```bash
g++ -std=c++23 -Wall -Wextra -pedantic src/main.cpp src/Student/Student.cpp src/StudentGrades/StudentGrades.cpp src/StudentManager/StudentManager.cpp -o StudentManagement
```

Стартиране:

```bash
./StudentManagement
```
